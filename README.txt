NONVERBALE'S FIRST MINECRAFT BASE — VERSION 1
GitHub Pages-ready website (small files and casual media-save deterrents)

1. Extract the ZIP. Upload the contents of the extracted folder to the root of your GitHub repository. Do not upload the ZIP alone.
2. Preserve folders assets/, scripts/, styles/, and floorplans/, plus index.html and construction-highlights.mp4.
3. In repository Settings > Pages select Deploy from a branch, main, /(root).
4. Visit the published website. If media fails, ensure every subfolder uploaded in the correct location.

Media saving: right-click on photos/video is disabled, image dragging is blocked, and the direct download buttons are removed. Video remains playable. These are deterrents only: public media still reaches viewers' browsers, and cannot be made truly non-downloadable on GitHub Pages. Screen captures, browser developer tools and recordings remain possible.

The 3D viewer preserves right-drag panning, orbit/zoom, and normal controls. The video remains a separately hosted 85-second MP4. Website is a close but imperfect reconstruction of the original ATM10 base.

Publication note: review rights for redistributed mod textures and other game assets before public hosting.
