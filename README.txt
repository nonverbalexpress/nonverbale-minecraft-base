NONVERBALE'S FIRST MINECRAFT BASE — VERSION 1

An interactive showcase of my first Minecraft base, featuring a 3D reconstruction, original gameplay screenshots, and construction footage.

This project was created to preserve and share a completed build and the memories associated with it.

Please note: The 3D viewer is a visual reconstruction and may not perfectly represent every detail of the original Minecraft world.

This is a personal, noncommercial fan project and is not affiliated with Mojang Studios or Microsoft.
